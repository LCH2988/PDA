1. VERTICAL 垂直系統

垂直刻度與通道選擇

用於調整電壓幅度（Volts/div）與信號垂直位置。按下對應通道數字按鈕（1、2、3、4）可開啟或關閉該通道。

Position 旋鈕： 上下移動波形。按下（Push to Center）可直接使波形歸零居中。
Scale 旋鈕： 順時針放大（減少 V/div），逆時針縮小。按壓（Push Fine）切換粗調/微調模式。
Math / Ref / Bus 按鈕： 開啟數學運算（如 Ch1 - Ch2, FFT）、參考波形比對或串列匯流排解碼（I2C, SPI, UART）。

標準五步驟快速量測流程 (SOP)

新手初次上機量測推薦標準作業步驟

STEP 1

接線與探棒校正 (Probe Comp)

將被測探棒連接至 Ch1，探棒夾子鉤住機台右下角 PROBE COMP 方波測試端子，接地夾接地。

🔍 觀察是否為平整方波；若平頂過衝或圓弧，請用非金屬螺絲起子微調探棒補償電容。
STEP 2

按下 AUTOSET 按鈕

按下右下角的 Autoset 按鍵。示波器將自動偵測訊號的振幅與週期，調配最適宜的 V/div 及 Sec/div 顯示。

💡 若欲恢復原廠初設，可按旁邊的 Default Setup。
STEP 3

設定觸發 (Trigger) 電位

旋轉 TRIGGER Level 旋鈕，確保畫面右側黃色觸發標籤介於波形高低電位之間，使波形穩定停格。

🎯 快捷方式：按下 Set to 50% 可自動將觸發電位設為訊號中央。
STEP 4

啟用自動量測 (Measure)

在觸控螢幕右上角點擊 Measure，新增 Peak-to-Peak (Vpp)、Frequency、RMS 或 Duty Cycle 等自動量測數據。

📊 點選 Results Table 可開啟統計數據總表（最大/最小/標準差）。
STEP 5

儲存結果至 USB 隨身碟

將 USB 隨身碟插入前面板插槽，按下右下角 Save 按鍵，即可將當前螢幕畫面 (PNG/BMP) 或波形數據 (CSV) 存入。

💾 存檔路徑與格式可於 File選單中進行前置設定。

面板按鍵與選單快速字典 (Control Dictionary)

按鍵名稱、按壓動作 (Push Action) 與功能導覽

按鍵 / 旋鈕標籤 歸屬區域 按壓動作 (Push Action) 主要用途描述
1, 2, 3, 4 VERTICAL 開啟/關閉通道選單 控制對應模擬通道之開關、耦合方式 (AC/DC/GND) 與衰減比。
Position (Vertical) VERTICAL Push to Center (零點居中) 調整該通道波形於畫面上的上下基準位置。按壓可快速歸零。
Scale (Vertical) VERTICAL Push Fine (微調切換) 改變垂直電壓伏特檔位 (V/div)。按壓切換 1-2-5 步進或精細連續微調。
Position (Horizontal) HORIZONTAL Push to Center (時間居中) 左右平移時間軸，更改觸發點相對於畫面中央的位置。
Level (Trigger) TRIGGER Push Set to 50% (自動 50%) 設定觸發判定之電位高度。按壓自動將電位調整至當前訊號振幅中點。
Multipurpose A / B SYSTEM Push Fine / Select (確認/精細) 多功能雙旋鈕。用以快速移動 Cursors 游標位置或調整參數。
Run / Stop ACQUISITION - 切換連續波形擷取（綠燈表示連線中，紅燈表示目前凍結停止）。
Single / Seq ACQUISITION - 單次擷取模式。待滿足一次觸發條件後自動停止，適合抓取開機瞬態與突波。
Autoset ACTIONS - 一鍵自動偵測輸入訊號並調整至最佳垂直/水平刻度。
Save ACTIONS - 快捷一鍵儲存。將當前畫面截圖或波形數據直接寫入至 USB 隨身碟。

安全注意事項與校正維護 (Safety & Calibration)

輸入過壓保護與接地規範

示波器通道與探棒具有最大安全電壓限制（如標示 300V CAT II）。請勿直接將探棒連接至高於規範之高壓電路。

所有類比通道的接地夾（Ground Lead）均於機身內與大地共地，切勿將接地夾接至非零電位的測試點，以免造成短路火花。
