1. 系統架構與特色

本系統專為運動社團（如鐵人三項、跑步、游泳、自行車俱樂部）設計，旨在解決傳統 LINE 群組接龍「格式混亂、難以統計、個資外洩、正候補計算繁瑣」等痛點。系統採用前後端分離架構，以極低的成本實現高效能的自動化管理。

📱 前端網頁特色 (HTML5 / LIFF)

  • 高齡友善 UI： 針對中高齡團員設計大字體、大按鈕，高對比色彩。
  • LINE 登入整合： 透過 LINE LIFF SDK 實現一鍵免輸入帳密快速註冊與登入。
  • 同行人快速報名： 允許主報名人幫家人、朋友代為登記，並可快速搜尋已建檔名單。

⚙️ 後端系統特色 (Google Apps Script)

  • 免費雲端資料庫： 直接使用 Google 試算表儲存資料，安全且完全免費。
  • 自動正候補計算： 依報名時間先後自動判定「正取」與「候補」，管理員一鍵重新遞補。
  • 個資安全保護： 公開名單自動隱藏手機、身分證與生日，僅管理員有權查看。

2. 系統部署指南

步驟一：準備 Google 試算表

建立一個新的 Google 試算表，並從網址列複製其試算表 ID（即 SPREADSHEET_ID）。

步驟二：部署 Google Apps Script 後端

  1. 在試算表點選「擴充功能」 > 「Apps Script」。
  2. 貼入後端代碼，修改最上方的 SPREADSHEET_ID。
  3. 在上方函式下拉選單選擇 setupDatabase 並執行以初始化工作表。
  4. 選擇 createFirstAdmin（請先修改代碼中您的 LINE ID）並執行以建立首位管理員。
  5. 點選「部署」 > 「新增部署」，選擇「網頁應用程式」，設定執行身分為「我」，存取權限為「所有人」，部署後複製產生的網頁應用程式 URL。

步驟三：設定 LINE LIFF 與前端

在 LINE Developers Console 建立 LIFF App，開啟 shareTargetPicker 權限，並將 LIFF ID 與步驟二的 GAS URL 填入前端 HTML 代碼中，最後將 HTML 部署至靜態網頁空間。

3. 會員操作說明

🔐

1. 登入與註冊

點擊「使用 LINE 登入」，系統會自動帶入 LINE 暱稱。首次登入需補全姓名、手機、生日、身分證字號等必填個資以完成註冊。

📝

2. 報名與新增同行人

選擇活動後點擊「我要登記」，可填寫自訂問題。若要幫親友報名，可點擊「新增同行人」或「搜尋已建檔名單」快速加入。

📋

3. 查詢與修改登記

在「我的登記」中可查看所有已報名活動。在活動截止時間前，會員皆可自由進去修改登記名單或取消報名。

⚙️

4. 管理員操作說明

📅 活動管理 (發布與編輯)

管理員可於後台新增活動，設定活動分類、名額限制（設為 0 代表無限制）、截止時間、地點與活動說明。並可自訂「報名問題」與「管理備註欄位」，滿足不同活動的客製化統計需求。

👥 名單維護與正候補重算

當有名額限制的活動報名額滿時，系統會自動將後續報名者設為「候補」。若有正取者取消，管理員可手動將其狀態改為「取消」，並點選 「🔄 重算正候補」，系統即會依報名時間先後自動將候補者遞補為正取。

🔑 權限管理 (多級管理員設定)

系統管理員 (Super Admin) 可搜尋並指定其他會員為一般管理員 (Admin)，並可精細授權其「可管理的活動分類」（例如：小張只能管理「自行車」類別的活動，無法修改「跑步」類別的活動）。

📢
